# Impro · 코드 연습

터치로 코드 진행을 만들고, 마디 카드를 드래그해 순서를 바꾸는 작은 Android 앱입니다. 마디별로 피아노 코드와 베이스를 재생합니다. 키보드 입력, 인터넷, 로그인, 별도 음원 파일 없이 작동합니다. Android 8.0 이상에서 설치할 수 있습니다.

## 설치

빌드된 `apk/impro-app-debug.apk`를 휴대폰으로 복사하고 파일을 열어 설치합니다. 설치 화면이 안내하면 해당 파일 앱의 **출처를 알 수 없는 앱 설치**를 허용합니다. 기존 앱을 업데이트할 때는 같은 서명 키로 빌드해야 합니다.

개인 설치용 debug APK입니다. Play 스토어 배포용 서명은 별도로 설정해야 합니다.

## 사용

1. **마디 카드를 터치**하면 아래에서 코드 선택창이 열립니다.
2. **루트음**(C–B), **♭ / ♮ / ♯**, **코드 종류**(메이저, 마이너, 7, maj7, m7 등)를 터치하고 **저장**합니다. 예를 들어 B → ♭ → m7을 누르면 Bbm7입니다. **쉼**을 누르면 NC가 됩니다.
3. **베이스 · 루트**를 누르면 슬래시 베이스를 고를 수 있습니다. 확장 코드는 **확장 코드 ▾**에서 선택합니다.
4. 마디 선택창에서 **+ 코드**로 한 마디에 코드 1–4개를 넣습니다. 위쪽 코드 버튼으로 편집할 코드를 선택합니다. 각 코드의 박수는 균등하게 나눕니다. 4/4에서 코드 2개는 각각 2박입니다. **취소**하면 편집 전 상태를 유지합니다.
5. **카드를 길게 눌러 드래그**한 뒤 원하는 마디 카드 위에 놓으면 그 위치로 이동합니다. 중간 마디들도 함께 밀려납니다. 카드 밖에 놓으면 이동을 취소합니다. 화면 위·아래 가장자리에서 드래그하면 자동으로 스크롤합니다.
6. **+ 마디**로 새 마디를 만들고 **마디 추가**로 확정합니다. **복제 / 삭제**는 선택한 마디에 적용됩니다. **↶ 되돌리기**로 최근 편집을 되돌립니다. 프리셋 적용도 되돌릴 수 있습니다.
7. 템포(40–240 BPM), 박자(3/4 또는 4/4), 반복 재생, 메트로놈을 설정하고 **재생**합니다. 항상 첫 마디부터 연주합니다. 현재 마디, 코드, 박, 다음 코드, 코드 구성음이 표시됩니다.
8. **정지**로 멈추고, **처음으로**로 표시를 첫 마디로 돌립니다.

코드 편집은 저장하거나 이동하는 즉시 자동 저장됩니다. 설정도 저장됩니다. 재생 중 편집·드래그·설정 변경은 잠기며, 앱을 벗어나거나 통화 등으로 오디오 포커스를 잃으면 정지합니다. 이어폰을 분리해도 정지합니다. 재생 중 화면은 켜져 있습니다.

최대 64마디, 한 마디당 코드 4개입니다. 마지막 마디 하나는 삭제할 수 없습니다. 최근 30개 편집까지 되돌릴 수 있으며, 앱을 다시 시작하면 되돌리기 기록은 초기화됩니다. 버전 1.0에서 저장한 코드 진행은 버전 1.1에서도 불러옵니다.

주요 코드: 메이저/마이너, `7`, `maj7`, `m7`, `6`, `m6`, `6/9`, `add9`, `9`, `m9`, `maj9`, `11`, `m11`, `13`, `maj13`, `sus2`, `sus4`, `7sus4`, `dim`, `dim7`, `m7b5`, `aug`, `7b5`, `7#5`, `7b9`, `7#9`, `7#11`, `7alt`, 슬래시 베이스. 이전 버전에 저장된 유효한 별칭도 유지합니다.

소리는 직접 합성한 피아노 계열 음색과 베이스입니다. 원본 Impro-Visor의 SoundFont, 스윙/드럼 스타일, 멜로디 생성 기능은 포함하지 않습니다. Bluetooth 출력은 기기의 오디오 지연 때문에 마디 표시보다 늦게 들릴 수 있습니다.

## 빌드

Java 17, Android SDK 35, Gradle 8.13 / Android Gradle Plugin 8.8.2를 사용합니다. Android Studio에서 이 폴더를 열거나 다음 명령을 실행합니다.

```powershell
# Android SDK 위치를 local.properties에 지정하거나 ANDROID_HOME 설정
./gradlew.bat :app:assembleDebug :app:lintDebug
# 생성 위치: app/build/outputs/apk/debug/app-debug.apk

# Android 기기와 무관한 코드/합성 엔진 검사
./scripts/test-engine.ps1

# 화면 시작, 코드 선택·취소, 드래그 이동, 되돌리기, 설정 복원 검사 (Robolectric)
./gradlew.bat :app:testDebugUnitTest

# 검사와 APK 복사를 함께 수행
./scripts/build-apk.ps1
```

Gradle wrapper는 최초 실행 때 Gradle을 내려받습니다. `local.properties`는 각 PC의 SDK 경로이므로 Git에 포함하지 않습니다. Windows SDK 경로는 `/` 구분자를 사용하면 편합니다.

## Impro-Visor 참고 범위

[Impro-Visor/Impro-Visor](https://github.com/Impro-Visor/Impro-Visor)의 소스를 읽고 다음 설계를 참고했습니다.

- [`ChordSymbol.java`](https://github.com/Impro-Visor/Impro-Visor/blob/master/src/imp/data/ChordSymbol.java)의 `makeChordSymbol`: 루트, 코드 종류, 슬래시 베이스를 분리하는 코드 표현.
- [`Leadsheet.java`](https://github.com/Impro-Visor/Impro-Visor/blob/master/src/imp/data/Leadsheet.java)의 `populatePartWithChords` / `addToChordPart`: 마디 단위 코드 진행, 마디 내부 균등 분할, `/`로 직전 코드 유지.

원본 Java Swing 애플리케이션의 소스, 리소스, 코드 사전, 로고를 복사하거나 포함하지 않았습니다. Android UI, 파서, 보이싱 선택, PCM 음원 합성, 재생 엔진은 이 프로젝트에서 독립적으로 작성했습니다. 따라서 원본에서 지원하는 모든 코드 기호와 `.ls` 리드시트 파일 형식을 지원하는 것은 아닙니다. 원본의 저작자 및 라이선스 정보는 해당 저장소에서 확인할 수 있습니다.
